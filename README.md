# Smart Task Manager with AI Assistance

This is a task management application built using Next.js 15 and TypeScript
(.tsx). It allows you to add, edit, and delete tasks, and also generate smart
subtasks using the Google Gemini API (via SDK).

---

## 🚀 Features

- Add, edit, and delete tasks
- Task fields: title, description, status (pending/completed), due date
- "Suggest Subtasks" button that uses Gemini AI to break a task into 3–5 smaller
  actionable steps
- Responsive design with Bootstrap (BT)
- Clean and simple UI
- Next.js API route integrated securely with Gemini SDK

---

## 🧠 AI Subtask Example

**Task:** Prepare for job interview

**AI Suggestions:**

1. Research the company and role
2. Practice common interview questions
3. Review and update your resume
4. Prepare questions to ask the interviewer
5. Choose appropriate interview attire
